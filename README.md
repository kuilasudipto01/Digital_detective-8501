# Digital Detective — Diwali Independent Learning Assignment

## Project Overview
This repository contains my work for the **Digital Detective** independent learning assignment. The assignment explores how computers work — from hardware fundamentals and terminal operations to operating systems, programming, number systems, Git workflows, and networking.

Each mission is completed and committed separately in its own folder with a dedicated README.

## Topics Explored
- Input-Process-Output-Storage (IPOS) model
- Hardware and software classification
- Terminal / command-line operations, flags and pipes
- Operating system responsibilities, processes, paths and permissions
- Compilers vs interpreters
- Binary, decimal and hexadecimal number systems
- ASCII and UTF-8 text encoding
- Git version control, branching and Pull Requests
- Computer networks, DNS and client-server architecture

## Running the Number Converter
```bash
cd mission-05-numbers-data
python3 number_converter.py
```
Enter a positive decimal number when prompted. The program displays the binary and hexadecimal equivalents.
