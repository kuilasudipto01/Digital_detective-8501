## 2. Work Completed

## 4. My Understanding

### IPOS Trace — Typing and Saving a Document

| Stage | What Happens | Hardware / Component |
|-------|-------------|---------------------|
| **Input** | I press keys on the keyboard to type text into a document | Keyboard |
| **Processing** | The CPU receives the keystrokes, the word-processing application processes them and updates the document in memory (RAM) | CPU, RAM |
| **Output** | The updated text appears on the monitor screen in real time | Monitor / display |
| **Storage** | When I press Save, the file is written to the SSD so it persists after the computer is turned off | SSD |

### Hardware and Software Identification

| Item | Hardware or Software? | Software Type | Purpose |
|------|----------------------|---------------|---------|
| Keyboard | Hardware | N/A | Used to enter text and commands |
| Monitor | Hardware | N/A | Displays visual output to the user |
| RAM | Hardware | N/A | Temporarily stores data the CPU is actively using |
| SSD | Hardware | N/A | Stores files and data permanently |

| VS Code | Software | Application | Code and text editor for writing programs and documents |

### Computer Systems Around Us

| System | Main Purpose | One Input | One Output |
|--------|-------------|-----------|------------|
| ATM | Allows bank customers to withdraw cash and check balances | Debit card and PIN via keypad | Cash dispensed and receipt printed |
| Smart TV | Streams video content and runs apps | Remote control button presses | Video and audio played on screen and speakers |
| Traffic signal | Controls vehicle and pedestrian flow at intersections | Timer / sensor detecting vehicles | Red, yellow and green lights displayed |
